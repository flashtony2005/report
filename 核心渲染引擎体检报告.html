一、本轮已修复（全部通过双端回归）

1. 非 A4 页面的边距吸附线错位正确性缺陷
证据：SmartGuides.ts:199-202 右/下边距内边界写死 (210 - margin.right) / (297 - margin.bottom)，而页面宽高取自 getPage()。
影响：100×150mm 标签、241×140mm 快递单等非 A4 页面，右边距吸附线跑到 202mm 处（页面外），拖拽吸附到错误位置。
改法：抽纯函数 guides/margin-snap.ts::computeMarginSnapLines(pageW, pageH, margin)，从页面尺寸推导；新增 4 条单测（A4 / 非 A4 / 零边距 / 中心）。
2. 字体 data-URI 每页重复加载与 base64导出性能
证据：export-engine/fonts.ts 的 fetchFontDataUri 无任何缓存；export-pdf.ts:116 每页调用 embedFontsInSvg(svg, PDF_FONTS)（思源宋体 10MB+）。
影响：N 页导出 = N 次网络读取 + N 次 base64（约 13MB/页）+ N 份副本写进 SVG，20 页可达数百 MB 瞬时占用。
改法：模块级双层缓存（按 src 缓存 data-URI Promise、按内容签名缓存 def→URI）；失败不留坏缓存，可重试。新增 5 条单测验证「3 页只 fetch 1 次」。
3. 文本度量缓存「满 5000 全清」大表分页
证据：layout-engine/measure.ts 两处 if (this.cache.size > 5000) this.cache.clear()。
影响：500 行 × 20 列 = 1 万唯一 key，越过阈值整体清空 → 命中率归零，每次重排 1 万次 getBoundingClientRect() 强制同步布局。
改法：抽出 measure-cache.ts——命中刷新 LRU、上限 20000、超限只淘汰最旧 25%。模拟实测：1 万 key 两轮访问命中率 0% → 50%，第二轮重排回流次数 1 万 → 0。
4. 临时 window 监听未纳入 dispose内存泄漏
证据：CanvasDesigner.ts 长按取消（touchmove/touchend）与空格平移（mousemove/mouseup）只在自身回调里移除。
影响：手势中途 dispose（切模板 / 组件卸载）→ 监听残留并持有 canvas 闭包。
改法：新增 addTempListener() 注册器，注册即进 cleanup 链，off 幂等。
5. ResizeObserver 重复重绘 + viewport 双发渲染抖动
证据：CanvasDesigner.ts:142-151 回调里 fitToContainer()（内部已 requestRenderAll + emitViewport）之后又重复一次。
影响：每次容器尺寸变化双发 viewport，React / Vue 两端各多一轮状态栏与面板重渲染。
改法：适配成功时不再重复；仅用户已手动缩放（跳过 fit）的分支保留重绘与广播。
