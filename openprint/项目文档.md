## 项目概述

**OpenPrint** 是一款开源、零后端依赖的 Web 打印模板可视化设计器。用户通过拖拽即可设计快递面单、发票、标签、报表等打印模板，支持 AI 一句话生成、云打印、C++ 桌面客户端静默打印，可快速对接 ERP 系统。

### 核心亮点

| 特性 | 说明 |
|------|------|
| **框架无关** | 核心渲染引擎与 UI 层完全解耦，引擎层纯 TypeScript 实现，零框架依赖 |
| **AI 生成** | 自然语言描述即可生成专业打印模板，支持快递面单、物流标签、仓储单据等场景 |
| **所见即所得** | 拖拽式设计，支持吸附对齐、标尺辅助、实时预览 |
| **多格式导出** | PDF / JPG / SVG / HTML 多格式导出，PDF 图表矢量渲染 |
| **批量打印** | Excel 数据直联，流水号自动编排，一行一标签批量输出 |
| **零后端** | 纯前端架构，本地存储模板，无需服务器即可完整运行 |
| **三主题** | 亮色 / 暗色 / 黑金（SVIP）三套主题，一键切换 |

## 核心引擎层（src/core）

核心引擎层采用**纯 TypeScript** 实现，零框架依赖，负责模板解析、数据绑定、分页排版、渲染与导出。设计器 UI、第三方集成（React/Vue/Angular/原生 JS）均通过 SDK 调用引擎。

### 排版引擎（layout-engine）

**职责**：将模板 JSON + 业务数据加工为「已定位、已绑定、已测量」的页面模型（`LayoutResult`），是整个系统的排版核心。

**内部模块**：

| 文件 | 职责 |
|------|------|
| `pagination-engine.ts` | 分页引擎主入口，`layout(template, data, options)` → `LayoutResult` |
| `data-binder.ts` | 数据绑定，将控件的 binding/expression/fixed 三种内容模式解析为最终值 |
| `expression.ts` | Mustache 表达式求值，支持 `{{field}}`、管道 `|`、`now()` 等函数 |
| `table-engine.ts` | 表格引擎，处理流式表格分页、表头/表尾重复、数据行渲染 |
| `table-cells.ts` | 单元格数据结构与工具（静态网格、单元格合并、尾行聚合 seed） |
| `group-engine.ts` | 分组引擎，按字段对数据分组，生成分组头/小计行 |
| `aggregate.ts` | 聚合函数（求和/平均/计数/最大/最小），用于表格尾行汇总 |
| `label-grid.ts` | 标签网格展开，将卡片模板按行列平铺，逐卡绑定数据 |
| `placeholder-scan.ts` | 占位符扫描，检测模板中的 `{{xxx}}` 变量 |
| `measure.ts` | 文本测量器，基于离屏 DOM 计算文本宽高，用于分页判定 |
| `header-footer.ts` | 页眉页脚色带（zone）处理 |
| `cell-format.spec.ts` | 单元格数据格式（日期/数字/货币/百分比） |
| `types.ts` | 排版引擎内部类型：`LayoutPage` / `PlacedControl` / `PlacedTable` / `RenderRow` 等 |

**核心数据结构**：

```
TemplateData → Document → Section[header/body/footer] → Component[]
    ↓ layout()
LayoutResult {
  pages: LayoutPage[]       // 每页含 header/body/footer 三组 PlacedNode
  metrics: PageMetrics      // 页面度量（物理尺寸/边距/内容区/页眉页脚高）
  warnings: RenderWarning[] // 渲染告警（绑定缺失/溢出/条码失败等 16 种）
}
```

**坐标系**：引擎内部一律用 mm，`PlacedNode.left/top` 相对所属 section 左上角（与协议层一致）。

### HTML 渲染器（renderer-html）

**职责**：接收排版引擎输出的 `LayoutResult`，将其转换为可打印的 HTML 字符串。

| 文件 | 职责 |
|------|------|
| `html-renderer.ts` | 主渲染器，`renderHtml(result, options)` → HTML 字符串，含转义/注入防护 |
| `css-generator.ts` | CSS 生成器，生成页面样式、表格样式、水印样式等 |
| `richtext.spec.ts` | 富文本渲染测试 |
| `css-generator.spec.ts` | CSS 生成器测试 |

**设计原则**：
- 引擎已完成所有排版计算，渲染器只做「数据 → 字符串」的机械翻译
- 严格的注入防护：文本 escape、CSS 值消毒、图片 src 协议白名单、富文本 DOMPurify 消毒

### 导出引擎（export-engine）

**职责**：将排版结果导出为 PDF / JPG / SVG 多种格式。

| 文件 | 职责 |
|------|------|
| `index.ts` | 统一导出入口，`exportPDF` / `exportImage` / `exportSVG` |
| `export-pdf.ts` | PDF 导出，jsPDF + 混合矢量（图表走 svg2pdf 矢量注入，其余栅格化底图） |
| `export-image.ts` | 图片导出（JPG/PNG） |
| `export-svg.ts` | SVG 导出 |
| `rasterize.ts` | SVG → Canvas 栅格化，高分原生渲染（scale=3，288dpi），PNG 无损底图 |
| `chart-svg-to-path.ts` | 图表 SVG 路径转换 |
| `fonts.ts` | PDF 字体注册（思源宋体 TTF 注入） |
| `util.ts` | 工具函数 |

**PDF 导出策略**：
- 混合矢量：文本/表格栅格化为 PNG 底图，图表用 svg2pdf 矢量注入
- 三重兜底：图表旋转 → 整页全栅格化；单图 svg2pdf 失败 → 该图单独栅格化；字体加载失败 → 全栅格化
- 默认 PNG 无损底图 + scale=3（288dpi·最高清）

### 图表组件（chartkit）

**职责**：纯 TypeScript + 原生 SVG 实现的轻量图表库，支持柱状图、折线图、饼图。

| 文件 | 职责 |
|------|------|
| `index.ts` | 统一入口，`renderChart(options)` → SVG 字符串 |
| `core.ts` | 核心绘图函数（坐标计算、弧形路径、图例布局、标签对齐） |
| `bar.ts` | 柱状图渲染器 |
| `line.ts` | 折线图渲染器 |
| `pie.ts` | 饼图渲染器 |
| `types.ts` | 图表类型定义（`ChartOptions` 含 `labelAlign` 等配置） |

**特性**：
- 三种图表类型：bar（柱状）、line（折线）、pie（饼图）
- 标签对齐：left / center / right 三档，默认 left
- 纯 SVG 输出，可直接在 PDF 中矢量渲染
- 中文优先字体：`'SourceHanSerifCN','PingFang SC',...`

### 模板规范与校验（spec）

**职责**：定义模板 JSON Schema 并提供校验能力。

| 文件 | 职责 |
|------|------|
| `template.schema.json` | 模板 JSON Schema 定义（AJV 校验用） |
| `validator.ts` | 校验器，`validateTemplate()` 返回校验结果，`assertTemplate()` 失败抛异常 |
| `validator.spec.ts` | 校验器测试 |

**错误类型**：`TemplateValidationError`，包含 `issues` 数组（`path` + `message`）。

### SDK（sdk）

**职责**：引擎对外唯一渲染契约，所有调用方（设计器、导出器、第三方集成）都通过 SDK 接入。

| 文件 | 职责 |
|------|------|
| `index.ts` | SDK 主入口，暴露 `render()` / `renderDocument()` / `dispose()` |

**核心 API**：

```typescript
// 完整渲染（排版 + HTML）
async function render(request: RenderRequest): Promise<RenderResponse>

// 仅排版（供 PDF/图片导出器复用，避免二次分页）
async function renderDocument(request: RenderRequest): Promise<LayoutResult>

// 释放共享测量器
function dispose(): void
```

**`RenderRequest`**：`{ template, data?, layout?, output? }`
**`RenderResponse`**：`{ html, pages, warnings, result }`

### 打印客户端（print-client）

**职责**：与本地桌面打印客户端（Qprint.exe / C++ Qt）的通信协议。

| 文件 | 职责 |
|------|------|
| `client.ts` | 打印客户端封装，发送打印请求到本地服务 |
| `payload.ts` | 打印载荷构建（页面图像 base64 + 打印参数），默认 PNG + scale=3 |
| `dpi.ts` | DPI 计算 |
| `orientation.ts` | 纸张方向处理 |
| `types.ts` | 类型定义 |

**通信方式**：HTTP POST 到本地服务（默认 `http://127.0.0.1:18888`），发送图像数据和打印参数，实现静默打印。

### 字体管理（fonts）

**职责**：字体目录与加载，支持系统字体检测与 Web 字体加载。

| 文件 | 职责 |

| `loader.ts` | 字体加载器（@font-face 动态注入） |
| `system.ts` | 系统字体检测 |

### 无头渲染（headless）

| 文件 | 职责 |

### 数学公式（mathkit）

## 设计器 UI 层（src/design）

基于 **Vue 3 + Naive UI + Fabric.js** 构建的可视化拖拽设计器。

### 整体布局

应用采用经典的三栏布局，由 `App.vue` 组织：

```
┌───────────────────────────────────────────────────────────┐
│  TopToolbar（顶部工具栏）                                  │
├──────────┬──────────────────────────────────┬─────────────┤
│          │                                  │             │
│ LeftPanel│         CanvasStage              │ RightPanel  │
│ (250px)  │         (中央画布)               │  (300px)    │
│ 控件库/  │  ┌──────────────────────────┐    │ 属性面板    │
│ 图层/    │  │  Fabric.js 画布          │    │             │
│ 数据源   │  │  (标尺+吸附+多页+水印)    │    │             │
│          │  └──────────────────────────┘    │             │
└──────────┴──────────────────────────────────┴─────────────┘
```

- **顶部工具栏**：新建/打开/保存/撤销重做/预览/导出/打印/主题切换/AI 助手
- **左侧面板**：三 Tab 切换（控件库 / 图层 / 数据源）
- **中央画布**：Fabric.js 渲染，支持拖拽、缩放、平移、多页、标尺、智能对齐
- **右侧面板**：选中控件的属性编辑器，可折叠

### 画布与控件（canvas）

#### CanvasDesigner

`CanvasDesigner` 类是 Fabric 画布内核，负责：
- 画布初始化与页面（白纸）渲染
- 缩放平移（viewportTransform）
- 控件增删改查
- 选中事件与属性同步
- 多页管理（页间间距、分页线、页码标签）
- 水印装饰层

**坐标约定**：
- 页面左上角 = 画布坐标 (0, 0)
- zoom=1 时 1mm = MM_TO_PX px（96dpi 下 ≈ 3.7795）
- 协议层坐标用 mm，画布层 px 换算由 CanvasDesigner 负责

#### 智能吸附对齐（SmartGuides）

`guides/SmartGuides.ts` — 拖拽时实时计算对齐参考线，支持左/中/右/上/中/下六种对齐。

#### 标尺（RulerOverlay）

`rulers/RulerOverlay.vue` — 标尺覆盖层，读取画布视口变换实时绘制刻度。

#### 控件（controls）

14 种 Fabric 控件类，全部继承自 `PrintObject` 基类（实现 `IPrintObject` 接口）：

| 控件类 | 类型 | 说明 |
|--------|------|------|
| `PrintText` | text | 文本控件（三态内容：fixed/value/binding） |
| `PrintRect` | rect | 矩形/圆角矩形 |
| `PrintCircle` | rect (circle) | 圆形（shape=circle） |
| `PrintLine` | line | 线条 |
| `PrintImage` | image | 图片 |
| `PrintBarcode` | barcode | 条形码（bwip-js） |
| `PrintQrcode` | qrcode | 二维码（qrcode 库） |
| `PrintTable` | table | 表格（含设计态渲染、单元格编辑） |
| `PrintRichText` | richtext | 富文本（Tiptap 编辑） |
| `PrintChart` | chart | 图表（柱状/折线/饼图） |
| `PrintMath` | math | 数学公式（KaTeX） |
| `PrintSignature` | signature | 手写签名 |
| `PrintZone` | zone | 页眉/页脚色带 |
| `PrintLabelGrid` | labelgrid | 标签网格（多列重复） |

**工厂函数**：`createFabricControl(control, page)` — 由协议模型创建 Fabric 对象。

|------|------|

## AI 助手（src/ai）

纯前端实现，直连 OpenAI 兼容 API，零后端依赖。

| 文件 | 职责 |
|------|------|
| `schema.ts` | Prompt 协议定义：系统提示词（模板协议+坐标系铁律）、Few-shot 示例（快递面单+会员卡）、Prompt 构建函数 |
| `client.ts` | LLM 客户端：SSE 流式调用，兼容 OpenAI/DeepSeek/通义/Moonshot，错误友好提示 |
| `generate.ts` | 生成编排：三种模式（完整模板生成 / 基于当前模板修改 / 选中控件改写），结果经校验，失败自动重试 |
| `normalize.ts` | 输出归一化：将模型返回的 JSON 修正为可通过校验的模板，补默认值、坐标纠偏 |
| `ai.spec.ts` | AI 模块测试 |

**三种生成模式**：
1. **完整模板生成** — 从 0 生成新模板
2. **基于当前模板修改** — 对已有模板做增量调整
3. **选中控件改写** — 只修改选中的控件

**Prompt 组织**：System（协议全定义）→ Few-shot（2 个示例）→ User（需求描述 + 可选上下文）

```
用户拖拽设计
    ↓

    ↓

│                                                   │

│    ├─ data-binder（数据绑定 + 表达式求值）         │
│    ├─ table-engine（表格分页/分组/聚合）           │
│    ├─ pagination-engine（分页编排）               │
│    └─ measure（文本测量）                         │
│          ↓                                        │
│    LayoutResult（已定位页面模型）                 │
│                                                   │
│  renderer-html  →  HTML 字符串                    │
│  export-engine → PDF / JPG / SVG                  │
│  print-client → 本地静默打印                      │
│                                                   │
└───────────────────────────────────────────────────┘
    ↓
iframe 预览 / 文件下载 / 打印机输出
```
