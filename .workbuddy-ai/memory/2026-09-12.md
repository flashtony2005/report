## 引擎差距分析（对照 PDF 资料）
- 产出 `引擎差距分析-对照PDF资料.md`，把资料结论逐条对照 print-server(Rust) + openprint/src/report/grid-report.ts。
- 引擎架构（实证，供后续直接引用，不必重查）：
  - 模型 `print-server/src/report/model.rs`：CellModel{ds, field, agg, expand_type(r/c), row_parent, col_parent, col_after, value_expr, expand_expr, format}；CellTpl{pos, value, model, merge_across, merge_down, merge_to_end}；CellInst 带 parent/col_parent/children/col_children/rows/expand_value/value/descendants/布局字段。
  - 引擎 `engine.rs` 四阶段：①主格树构建+递归展开(make_insts, :181) ②求值(:94-110，按 0..n 单遍，先 agg 后 value_expr) ③行布局(:112) + 列布局 layout_columns(:118) ④填网格(:120)。
  - 表达式 `eval_expr`(:419) 只支持 POS / POS[COORD] / .func()，func ∈ sum|count|avg|min|max|value(:559)；Coord 支持 `B3:+0`、`B3:-1`、绝对 `B3:1`(:527)。
  - 双向祖格注册 `register_descendants`(:246) —— 交叉表横向层次坐标的前提。
- 关键缺口（按优先级）：
  1. **无依赖引擎**：阶段2 按实例下标单遍求值，表达式格引用表达式格时结果依赖下标顺序（被引格下标更大则读到 Null）。最该先修。
  2. **无环检测**：make_insts/resolve/register_descendants 沿 parent 链递归/上溯，row_parent 成环会栈溢出；全库无 cycle/visited/深度上限。
  3. **无 `$` 运算符、`{}` 条件表达式、四则运算** → 同比/环比/累计差完全无法在模板表达。
  4. 无主格自动认定（无 row_parent 即挂根，engine.rs:44），模板成本高且配错静默算错。
- 已做对别动：col_after（列数不定不写死列号）、merge_to_end、双向祖格注册、多源不整合、grid-report.ts 是 Rust 模型 TS 镜像（前端只描述不计算）。
- 引擎层目前**没有报表语义分页**，只有 print_job.rs 的物理 @page CSS。
- 排查教训：zsh 会吞掉 `grep --include=*.rs` 的通配符，导致"搜不到"的假阴性——代码检索一律用 Grep 工具或给通配符加引号。

## NopReport 权威语义（校正了差距分析的两条结论）
- 来源：官方开发文档 https://nop-platform.github.io/projects/nop-entropy/docs/dev-guide/report/xpt-report/ + 知乎源码解析 https://zhuanlan.zhihu.com/p/663964073 。**我们的 model.rs 自称「NopReport xpt 的 JSON 等价物」，所以这份语义就是目标规格，优先级高于 OCR 论文。**
- 父格缺省规则（已确认，可补）：`rowParent` 不指定→**向左**查最近 expandType 格；`colParent` 不指定→**向上**查；显式 `A0` = 根。与论文「默认父格自动上溯」一致，双份材料互证。
- 不必抄润乾 `$`/`{}`：NopReport 用 `ExpandedCellSet.getValue()` 返回首格值 + 编译期把 `A3` 重写为 `A3.value` 统一单值/集合；环比写 `IF(B4.expandIndex > 0, C4 / C4[B4:-1], '--')`。**我们真正缺的是完整表达式引擎（算术+IF+函数）**。
- 值三阶段：expandValue（展开期，层次坐标不可用）→ value（展开完，层次坐标可用）→ formattedValue（formatExpr > dict > Excel 格式串）。
- 我们全缺的展开属性：keepExpandEmpty / expandMinCount / expandMaxCount / expandInplaceCount / rowTestExpr / colTestExpr / exportFormula。
- 展开顺序：NopReport 用**迭代 deque + 父格优先 push**（非递归）——既避免栈溢出也好加环检测，建议替代我们递归的 make_insts。
- 函数集官方 11 个，我们 6 个；缺 PRODUCT/COUNTA/NVL/PROPORTION(占比)/RANK/ACCSUM(累计)，占比和累计是高频刚需。
- 官方 `dump=true` 调试：展开中间结果逐个输出 `{seq}-{cellPos}.html`，内容 `cellText <- cellLayerCoordinate` —— 强建议抄。
- 论文 BEB→BE→BoxCE ≈ NopReport ExpandedCell(rowParent/colParent + rowDescendants/colDescendants + expandedValue/value)；两份独立材料在默认父格上溯、双向后代注册、展开求值分离三点一致。
- 差距分析已按以上校正，`引擎差距分析-对照PDF资料.md` 新增「NopReport 权威语义清单」一节，动手顺序改为 8 步。

## 核对 GitHub 上游后补齐：$ 运算符 + 条件表达式 {}（主格自动认定已实现）

- 上游：`entropy-cloud/nop-entropy`（sparse clone `nop-report`，201 个 java 文件）。
  `git sparse-checkout set nop-report` 很好用，不用拉整个大仓。
- **NopReport 没有 `$` 运算符**（全仓搜不到）。它用 `IF("<条件>", <格集>)`：
  `ExcelFormulaParser.java:83-97` 把条件串包成 `e=>(条件)` 箭头函数，
  `FilterCellSetExecutable` 执行 `cellSet.filter(e -> ...)`，候选格绑成 lambda 参数 `e`。
- 我们实现的是润乾语义（超集）：`POS[COORD]{条件}`，裸 `B2` = 候选格的主格，`$B2` = 当前格的主格。
  - `expr.rs` 新增 `Expr::Filter{cell,cond}` / `Expr::Dollar(inner)` + `parse_filter_cond()`；
    条件可写在聚合后缀前后（`C2[A2:-1]{...}.sum()` 与 `C2[A2:-1].sum(){...}` 都收）。
  - `engine.rs`：`eval_ast(e, cur, outer)` 增加 `outer`。过滤时 cur=候选格、outer=当前格，
    `Expr::Dollar` 用 outer 求值。用 python 正则批量改的签名/调用点。
- **挖出真 bug**：`eval_cmp` 原来只比数字，条件里比分组标签（"1月"/"华东"）恒假 → 筛完永远空集，
  不报错只静默变空。改为非数值走 `Val::as_text()` 文本比较。为此给 `Val` 加了 `#[derive(Clone)]`。
- 测试：同比 `C1[A1:-1]{$B1==B1}` → ["","","100","200"]；反向 `{B1==B1}` 恒真 → ["","","100","100"]。
  **Rust 70 全绿**。
- 主格自动认定：上游 `XptModelInitializer` 注释「缺省左侧最近的展开单元格为行父格，
  上方最近的展开单元格为列父格」→ 与我们一致。但上游另有 3 条细化规则我们没做
  （跟随相邻格的父格 / 扫不到时取最左格·第一行的父格 / 展开范围内不同行的格子默认挂它），
  已在文档列表记明，日常模板一般被「向左扫」覆盖。

## rowTestExpr / colTestExpr（整行 / 整列删除）

- 不需要「按物理行反查实例」：求值在布局之前，直接在布局期筛掉即可。
  `layout_group` 入口过滤 row_test_ok；`layout_columns` 跳过 col_test_ok + `mark_col_dropped` 递归。
- `CellInst.dropped` **缺省 true**，`place()` 落位时置 false →
  「从未被布局访问到的实例」天然就是被删的，父格被删不必再遍历子树打标记。
- 解析失败按「保留」+ 告警（静默删行=丢数据，比多留一行危险）。
- ⚠️ **踩坑 / 修复上一轮真 bug**：`make_insts` 有**两条**实例创建分支（展开格 / 非展开格）。
  上一轮补 format_expr/dict 时只拷了非展开分支 → **挂在分组格（展开格）上的字典静默失效**。
  这次补 row_test_expr 时撞见，两条分支都已同步。
  **教训：往 CellInst 加字段，两个分支都要拷。**
- 已知限制：测试表达式里 `C1[B1:+0]`（以本格自己为主格相对定位）取不到值——
  相对坐标基准要从当前格的**祖先链**找主格，本格不在自己祖先链里。
  规避：条件写在主格的子格上，或用 `value` 比对本格自身值。
