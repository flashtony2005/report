## xlsx 导出：加细边框 + 打印时表头跨页重复（用户选的「最经济高效」）

`to_xlsx(sheets, repeat_rows)` 第二参数取模板分页配置的 `repeat_header_rows`
（与分页渲染同一个值），没配分页取 1。它同时管两件事：
**前 N 行用表头样式**（顺带修好「多行表头只有第一行有样式」）+ `set_repeat_rows(0,N-1)`。

三个坑：
1. **合并区内部不能单独写值** —— 给空格子补边框会撞上合并区，用 `covered` 集合跳过。
2. 空格子要 `write_blank` 补边框，否则网格到处缺口。
3. `repeat_rows` 必须 `clamp(1, 行数)`：0 或超界让 `set_repeat_rows` 报错，
   失败形态是「点了导出没反应」。测试 `repeat_rows_out_of_range_is_clamped`。
4. `xlsx_handler` 必须在 `render_with_sources` **之前**取 `req`（它把 req 吃掉）。

**这类改动单测证明不了**（xlsx 是 zip，内容压缩过）。解法：
`scripts/verify-xlsx-export.py <file> --expect-repeat N` 拆 zip 读 XML 校验
thin 边框 / 每格都有格式 / `_xlnm.Print_Titles` 范围是 `$1:$N`。

⚠️ **写校验脚本时踩到自己的盲区**：最初只查 `s="…"` 属性，结果**去掉边框反而「通过」**
—— 没有格式的格子压根不写 `s`，直接被跳过。是**故障注入探针**暴露的。
→ 教训：写完检查脚本后注入已知错误；只查「有属性」的，别忘了「没属性」的那种。

真机实测（print-server 18893）：分页模板 repeat_header_rows=2 → 三张页都是 `$1:$2`，
第 1、2 行表头样式、第 3 行起正文，全部格子 borderId=1。两个探针各验过（去边框→红、
去 set_repeat_rows→红）。Rust 171 passed，镜像一致。
