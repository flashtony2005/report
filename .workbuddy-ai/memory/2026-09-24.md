## AI-first 差距分析（本次主要交付）

用户问：「本项目与当前 AI-first 理念的差别，如果要 AI-first 如何改进」。

**交付**：`AI优先-差距分析与改进方案.md`（仓库根，与既有 `引擎差距分析-*.md` 同位置同风格）。

### 核心结论

**本项目已经是「AI 可验证」的，但不是「AI 可编写」的。**
- 可验证：探针 / 故障注入 / 可判定不变量 —— 正是 AI-first 需要的地基。
- 不可编写：AI 只挂在**自由画布**那一层；差异化内核（`ReportDef` / `CellTpl` / 主格 / 表达式）对 AI 完全不可见。
- 且：画布协议**三份声明已漂移**，漂移**已造成静默删控件 bug**（已复现）。

### 先纠正的前提（重要，别再说「本项目没有 AI」）

`openprint/src/ai/` **716 行 5 个文件** + `designer-react/src/modals/AiAssistantModal.tsx` 完整接入。
含提示词/few-shot/流式客户端/**校验→回喂结构化错误→重试 1 次**/归一化修复，三模式（新建/改当前/只改选中）。

**这是靠 grep 发现的，不是靠依赖清单** —— 又一次印证「判断某能力有没有，先 grep 源码」。

### 复现的 bug（本次最硬的一条）

三份「控件类型」声明：schema 13 个 / `normalize.ts` 白名单 9 个 / 提示词散文 8 个。
`normalizeControl` 对白名单外的 type 返回 `null` → 被 filter 丢掉 → `diffSelectedControls` 算进 `removedIds` → `removeControl` **删掉控件** → 还弹**绿色成功**。

即：**选中画布上的图表控件让 AI 改配色 → 控件消失，界面说成功。**

复现：`text`/`zone` 过；`chart`/`math`/`signature`/`labelgrid` 返回 `[]`（4 failed / 2 passed）。
脚本见 `REFERENCE.md` §二十.2（`normalize.ts` 只有 `import type`，可单文件隔离跑）。

**通用教训**：一份协议有 N 处并行声明 = N 处会漂移，且漂移是静默的。
解法不是「记得同步」，是**写一条断言它们一致的闸，并证明这条闸能红**。

### 其他实测发现（都进了 REFERENCE §二十）

- **AI 的测试不在任何闸里**：`ts-test.sh` 只拷 `openprint/src/report/*.ts`，`ai.spec.ts` 没有脚本会跑。
- **错误两套方言**：业务错误 = 中文 `text/plain`（`(StatusCode, String)`）；axum `Json` 提取器错误 = 英文 serde 散文 + 422。**无错误码**。
- **时间格式不统一**：`/api/reports` 是 UTC `…Z`，`/health` 是本地 `+08:00`。
- **内外两层形状**：`/api/report/sample-template` 给**内层** `{sheets,datasets}`；`/api/reports/:id` 给**外层 `ReportDef`**（实测 10 键）。**`ReportDef` 没有 JSON Schema**。
- **样例报表开箱不可跑**：`sales-by-region.json` 指向 `/tmp/report-demo.db`，该文件不在仓库 → `run` 直接 400。
- **没有 MCP**：`grep -rl 'mcp|modelcontextprotocol'`（排除 node_modules）0 命中；33 条路由全是给人用的 REST。
- **已有的自检地基**（AI-first 现成材料）：`RenderResponse.warnings`（是散文且 `Option`）、`dump=true` 展开轨迹（默认关）、`/health` 暴露 `reportsDir`/`odbc`。
- **坐标纠偏是启发式**（`normalize.ts:87-104`）会双向错：只错一个轴不触发；合法设计两轴恰在 margin 上会被无端平移。

### 改进路线（写在文档里，分 4 阶段）

0. 收敛真相 + 让静默失败变响（一致性闸 / 丢弃要出声 / AI 测试进闸）
1. 内核暴露成可生成可校验（`ReportDef` schema / capabilities 端点 / 生成器变 API / 错误结构化）
2. 工具面（MCP / `template.validate` 独立成工具 / warnings 结构化并默认开）
3. 闭环（AI 扩到非线性报表 / 用 dump 做自检 / 凭证上移）
