## 新踩的坑：`cargo test` 不会刷新 `target/debug/print-server`

真机探针跑出来「成环没告警」，几乎得出「告警没进 HTTP 响应」的结论 ——
其实是**二进制是旧的**：那几轮只跑了 `cargo test`（它构建的是 test harness），
没跑 `cargo build`，所以 `--port` 启的那个 bin 还停在改动之前。

→ **真机探针前一定先 `cargo build`**，别指望 `cargo test` 顺带把 bin 更新了。
判据：探针结果与单测结论不一致时，先怀疑二进制版本，再怀疑代码。

## 实测盘点「还剩什么没做」（用户问「根据实际现在报表还要实现什么功能」）

对着代码 grep 出来的，不是照着文档抄。**先排除假缺口，再列真缺口。**

**订正一处我自己的错**：上一版写「没有图表库」是错的。图表是**自研**
`openprint/src/core/chartkit`（bar/line/pie，纯函数出 SVG，零第三方依赖），
只是**只覆盖画布侧** —— `print-server/src` 里 grep `chart` 零命中。
教训：没装第三方库 ≠ 没这能力，先 grep 再下结论。

**假缺口（其实都做了）**：`CellModel` 19 个字段无死字段（逐个统计引用，
`engine.rs` 都有真实读点）；分页 `paginate()`（`mod.rs:319`）真的生效，不是死配置；
多 sheet 导出支持（`xlsx.rs:37` 循环 `add_worksheet`）；图片/条码/二维码画布侧已有。

**真缺口按影响排序**：
1. **格子没有作者定义的样式** —— `GridCell`(`model.rs:379`) 只有 7 个字段，
   字体/字号/颜色/边框/对齐/条件样式一个都没有。设计器里看到的彩色是**语义高亮**
   （`grid-report.ts:661-666` 扩展黄/扩展绿/字段蓝/表达式紫），标的是「什么角色」
   不是「长什么样」，且不导出。→ 这是和润乾观感差距最大的一块，且是完整链路
   （模型 + mirror + xlsx + 面板）。
2. **分页不认分组** —— `paginate` 渲染后按固定行数切，不知道哪几行同组，
   跨页时第二页补不出主格（表头重复只重复模板前 N 行）。`mod.rs:313` 注释
   已声明不做润乾 9 类带区模型。
3. 图表/图片进不了服务端报表。
4. ODBC 引擎未实现（界面已标注，非静默坑）。
5. `esc`/`tsc`/`zpl` 票据指令未实现（`print_job.rs:85`）；`/print` 只有 pdf/html。
6. **报表参数/查询表单整块缺失** —— `params` 只是 SQL 绑定参数，没有
   「打开报表前弹条件 → 注入过滤」这层。
7. 无 CSV 导出。
8. MySQL 归一成 sqlite，**但 UI 下拉只有三项**（`admin.html:407`），不可达，优先级最低。

**结论**：内核（展开/层次坐标/表达式/主格/跨数据集/分页/告警）已经齐了，
缺的是「长相」和「外延」。
